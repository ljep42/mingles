# mingles

A cross-platform Flutter app to meet local singles in the area.

## Scaffolded project structure

This repository now contains a minimal Flutter app skeleton for `mingles`:

- `pubspec.yaml` - Flutter package/dependency configuration
- `analysis_options.yaml` - lint configuration
- `lib/main.dart` - app entrypoint and starter UI
- `test/widget_test.dart` - starter widget test

## Next steps

1. Install Flutter and Dart locally.
2. From this repository root, run:

   ```bash
   flutter pub get
   flutter test
   flutter run
   ```

3. (Optional) Generate platform folders if needed:

   ```bash
   flutter create --platforms=android,ios,web,linux,macos,windows .
   ```
